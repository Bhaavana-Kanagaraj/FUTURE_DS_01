# Business Sales Performance Analytics Report

---

# 1. Introduction

The objective of this project is to analyze business sales data and identify important business insights related to:
- revenue trends,
- profitability,
- product performance,
- category performance,
- and regional sales analysis.

This project helps organizations make data-driven business decisions.

---

# 2. Objectives

The main objectives of this analysis are:

- Analyze overall sales performance
- Identify top-performing categories and products
- Evaluate regional sales performance
- Analyze profit trends
- Detect loss-making products
- Generate actionable business insights

---

# 3. Tools & Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code
- Power BI

---

# 4. Dataset Description

The dataset contains business sales transaction data including:
- Order details
- Product categories
- Sales
- Profit
- Quantity
- Region
- Shipping details
- Customer information

---

# 5. Data Cleaning & Preprocessing

The following preprocessing steps were performed:

- Removed duplicate records
- Checked missing values
- Converted date columns into datetime format
- Created Month and Year columns
- Verified data consistency

## Sales Analysis

## Profit Analysis
- Category Profitability
- Regional Profitability

## Correlation Analysis
- Relationship between Sales, Profit, Discount, and Quantity

# 8. Key Insights

1. Technology category generated the highest sales revenue.
2. Certain products generated high sales but low profits.
3. Regional sales performance varied significantly.
4. Monthly sales trends showed seasonal patterns.
5. Discounts negatively impacted profitability in several cases.
6. Some products consistently generated losses and require business review.

---

# 9. Recommendations

- Reduce excessive discounting on low-profit products.
- Focus more on high-performing regions and categories.
- Improve inventory planning for top-selling products.
- Review pricing strategies for loss-making products.
- Use dashboard monitoring for continuous business analysis.
